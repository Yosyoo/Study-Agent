大学坝 | 学大坝 — Study Agent v0.1.0

首个早期体验版，将课程任务、浏览器观察、视频进度和 AI 题目解析集中在一个桌面工作台。

### 下载与使用

本次提供 **macOS Apple Silicon（M 系列）** 安装包。下载 `Study.Agent-0.1.0-arm64.dmg`，打开后将 Study Agent 拖入应用程序。已内置 Chromium，无需安装 Node.js 或开发工具。

首次启动后选择模型服务商、配置自己的 API Key，再打开学习浏览器手动登录学习通。支持 DeepSeek、Kimi、GLM、OpenAI、Claude、Gemini 预设和自定义服务。

### 版本说明

- 支持任务开始、暂停、恢复和接管，展示浏览器截图及待确认操作。
- 监测真实视频播放进度与异常状态。
- 从截图分析章节练习，提供答案建议和解析，不自动填写或提交答案。
- 本地已完成类型检查、构建、单元、浏览器与桌面流程测试；真实课程和模型效果仍待验收。

当前安装包未经签名或 macOS 公证，系统可能提示无法验证开发者。Windows 和 Intel Mac 安装包尚未提供。

`SHA256SUMS.txt` 可用于核对下载完整性。模型 API 调用费用由所选服务商收取。
