### 这次更新

- 新增「分析当前页面」：打开练习就能分析截图，无需创建任务；此模式不会点击、输入或跳转。
- 模型设置更简洁：官方厂商自动选择协议，测试连接和导入密钥不会切换当前模型。
- Gemini 改为原生 generateContent 接口，兼容已有官方配置与密钥。
- 暂停和人工核对不再消耗实际运行时限；视频结束后会有限等待平台完成标记。
- 浏览器按目标控件、地址、输入内容和滚动位置验证结果，动画变化不再被当作操作成功。
- 显示真实请求、重试和等待进度，改进 API 错误提示；误删任务可短暂撤销。
