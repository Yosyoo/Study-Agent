# Study Agent 界面设计

本轮按 Anthropic 的 [Frontend Design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 进行设计、实现、截图检查。使用场景是长时间打开的中文学习桌面工具，重点是当前课程、Agent 的运行状态和用户的下一步操作。

## 视觉约定

- 画布 `#FFFFFF`：内容区与表单。
- 侧栏 `#F5F6FA`：固定导航，弱化应用框架。
- 墨色 `#232838`：标题与正文。
- 次要文字 `#667085`：辅助信息，避免极浅小字。
- 学习蓝 `#4964D8`：主操作、当前导航、学习图形。
- 淡蓝 `#EEF2FF`：选中状态和答案建议。
- 成功、警告和异常分别使用绿色、琥珀色、红色，并始终配合文字或图标。

中文使用系统的苹方 / 微软雅黑，西文使用 Avenir Next / Segoe UI。正文 13–14 px，辅助文字 11–12 px，页面标题 26 px。界面不用装饰性的英文大写标签。页面标题、操作、列表和面板使用一致的左对齐轴线。

## 布局

```
固定浅色导航  | 平台 / 浏览器连接状态                       本地状态
             | 页面标题                              主要操作
             | 当前学习任务及开始、暂停、停止
             | 浏览器观察（主区域）             | 学习准备 / Agent
             |                                 | 视频状态
             | 最近操作（有记录时出现）
```

模型页采用厂商导航与单一编辑区。六家厂商使用本地 SVG 标识；常用配置仅显示模型和密钥，其他参数折叠。任务页采用连续列表，题目页以题干、选项、答案建议和原图对照建立阅读顺序。

## 设计自审

原方案的问题是深色框架过重、全页重复卡片、空状态与零值统计占据注意力、文字偏小。初版改进思路曾保留四张统计卡和横向引导卡，复审后删除：任务操作合并为一条，统计归入 Agent 状态，引导只在没有任务时出现。只为浏览器、题目和表单使用清晰边界；说明文字不另包卡片。

学习页面的空状态使用原创书页图形。它是界面插画，不是模拟课程截图或虚构学习结果。保持一个视觉重点，其余区域安静、紧凑。动效仅用于交互反馈和真实加载，支持减少动态效果。

## 验证范围

使用隔离的 Electron 配置进行功能回归与截图检查，覆盖首次使用、厂商切换、最小窗口、任务列表、视频监测、题目核对、错误反馈和弹窗。视觉测试中的课程、截图、题目和日志均为明确标识的本地测试资料，不代表真实学习通验收。

`npm run test:visual` 生成 24 个真实窗口截图。检查了横向溢出、标识图片加载、1100×720 最小窗口主要操作可见性、打开弹窗时的背景隔离和关闭时焦点恢复。截图缩放保留原始图像，原始尺寸对应浏览器 CSS 视口，方便核对公式和细节；它不改变 Agent 的截图坐标或授权流程。

复查中进一步修正了来源图过小、宽图查看器被普通弹窗宽度覆盖、小窗口模型状态折行、未添加密钥时的误导性“正在使用”文案，以及输入不支持地址时错误被弹窗遮挡的问题。回归脚本覆盖这些交互。

厂商 SVG 标识来自 Lobe Icons，许可随应用输出。应用书页图标为原创 SVG，源文件为 `build/icon.svg`，通过 `npm run icons:generate` 生成构建使用的 PNG，再由打包工具转换为平台图标。页面不加载远端字体、图标或图片。
